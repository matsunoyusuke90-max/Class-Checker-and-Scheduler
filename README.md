# 講義まとめ

大学の講義を「時間割・課題の締切・各回の記録」までまとめて管理できる、**1ファイル完結のWebアプリ**です。
インストール不要・サーバー不要。`index.html` をブラウザで開くだけで動きます。データはブラウザ内（localStorage）に自動保存されます。

---

## 特長

- **時間割ビュー** … 月〜金 × 1〜10限のグリッド。空きコマの「＋」から教科を追加、セルをクリックで詳細へ。集中講義にも対応。
- **締切順の課題一覧** … 全教科の課題を締切が近い順に表示。チェックで完了/未完了を切替（毎週課題は「今週分」を管理）。
- **教科ごとの詳細ページ**
  - 時間・区分・単位・場所・**Zoomリンク（ID/パスコードのコピー）**・**教材フォルダへのリンク**
  - **提出ファイル名**の雛形（`接頭辞_教科名_第〇回.pdf`）をワンクリックでコピー
- **課題・レポート管理** … 「毎週定刻まで（繰返し）」と「突発的な課題（単発・期限つき）」の2種類。残り日数を色分け表示。
- **授業の記録（各回）**
  - 「回」は**自由入力**。`2-1` のように番号の間に文字を入れられます（例：`2-1`＝授業用／`2-2`＝課題用 を同じ回に並べる）。
  - **その場編集**… どの回も、そのカードの位置でそのまま編集（上までスクロールしません）。
  - 各回に **📝 授業内容メモ／📌 課題／👥 グループワークまとめ** を整列。チェックでワンプッシュ追加・取消。
  - テキスト欄は**縦方向に自由リサイズ**。
  - 「レポート提出済み」フラグの切替。
- **バックアップ** … 「書き出し」でJSON保存、「読み込み」で復元（別端末への移行も可能）。
- **ダーク/ライト**や見やすい大きめフォントなど、読みやすさ重視のデザイン。

---

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari など）で開く。
2. 時間割の空きコマの **「＋」** から教科を追加する。
3. 教科をクリック → 詳細ページで
   - **課題・レポート**を追加（毎週／突発）
   - **「＋ 回を追加」** で各回の記録を作成
4. 記録の各回では、チェックで「課題」「グループワークまとめ」欄を出し入れできます。
5. 必要に応じて **「書き出し」** でJSONバックアップを取得。

> データはブラウザごと・端末ごとに保存されます。別のPCで使う場合は「書き出し」→「読み込み」で移行してください。

---

## データの保存について

- 保存先：ブラウザの **localStorage**（キー：`kogi-matome-public-v1`）。
- 入力すると**自動保存**されます。サーバーには一切送信されません（すべて手元のブラウザ内で完結）。
- ブラウザのデータ消去・別ブラウザ/端末では引き継がれないため、**定期的に「書き出し」でJSONバックアップ**を推奨します。

---

## 動作環境

- モダンブラウザ（Chrome / Edge / Firefox / Safari の最新版）。
- インターネット接続：不要（Zoomリンクを開くときのみ必要）。

## カスタマイズ

- 初期表示を自分用に固定したい場合は、`index.html` 内の `SEED`（初期データ）に教科を書き込めます。
- 保存キーを分けたい場合は `STORE_KEY` の値を変更してください（別アプリ扱いになり、データが分離されます）。

---

## ライセンス / 注意

個人利用向けの簡易ツールです。公開版（`index.html`）には個人データを含みません。
自分の講義データを入れて使う場合は、スクリーンショットや共有時に**Zoomのパスコード等の機微情報が映り込まない**ようご注意ください。
